# Julkisilla.info

Progressive web application for viewing the nearest public transport departures using the [Digitransit api](https://digitransit.fi/en/developers/).

## Usage

**Run unit tests**

```
npm run test
```

**Run integration tests**

```
npm run test:integration
```

**Run linter**

```
npm run lint
```

**Run svelte checker**

```
npm run check
```

**Start in dev mode**

_**Note:** Queries will fail because the Digitransit API key is missing_

```
npm run dev
```
